# 荔枝｜经验产品化起步助手

通过逐步提问，帮助有工作经验的职场人和接单自由职业者，从零散经历中找到一个值得验证的细分方向，并形成文档指南、咨询或接单服务的初步框架。

## 在 Agent 中安装

在支持技能安装的 Agent 中直接发送：

> 请从这个 GitHub 仓库下载并安装 liz-experience-product-coach 技能：https://github.com/wuhuili2014/productize-me。技能位于仓库根目录，请保留 SKILL.md、references 和 agents 的目录结构，并安装到当前工具的用户技能目录。

安装能力取决于具体 Agent 是否支持读取 GitHub 和本地技能。不要只发送“帮我下载这个 skill”，需要同时提供仓库链接。无需登录飞书或配置其他连接器。

## 开始使用

在 Codex 中发送：

> 使用 $liz-experience-product-coach，帮我梳理适合自己的经验产品化方向。

也可以说明自己的背景：

> 我做了五年运营，想发展一份副业，但不知道哪些经验可以变成产品。请使用这个技能，每轮问一个主问题，先帮我盘点真实案例。

其他支持 SKILL.md 的 Agent 可以要求“使用荔枝经验产品化起步助手”；具体加载方式以工具支持为准。

## 你会得到什么

- 有具体案例依据的经验技能清单。
- 结合喜欢程度、能力和市场证据的候选比较。
- 具体到人群、场景与问题的初步方向。
- 文档指南、咨询或接单服务的粗框架。
- 待验证假设和下一步小行动。

没有市场反馈时，会先给待验证构想，再帮助设计小调研。带着反馈回来，可以继续调整。它不会仅凭对话保证市场成立或预测收入。
