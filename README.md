# 荔枝｜经验产品化起步教练

你有几年的工作经验，也做成过一些事情，却不知道其中哪些经验可以整理出来卖给别人；或者你会的东西很多，反而不知道应该先从哪个方向开始。

「荔枝｜经验产品化起步教练」是一份可以安装到 Codex 等 Agent 中使用的 skill。它会像一位经验梳理教练，通过逐步提问，陪你从真实经历中盘点技能、比较方向，提炼可复用的经验，形成一份能照着开始验证的产品起步方案：先帮谁、解决什么、以什么形式交付什么结果，以及第一版做到哪里。

它不会一上来让你制作一套完整课程，也不会只根据兴趣替你拍脑袋选赛道。它会结合你做成过的事情、喜欢的工作方式、现实条件和已有的市场需求证据，帮助你先迈出更小、更可靠的一步。

## 它能帮你做什么

「荔枝｜经验产品化起步教练」更像一位经验梳理教练，会通过分阶段提问，帮你盘点真实经验和技能，并找到一个值得优先验证的可售卖产品方向。

这份 skill 会带你完成四个阶段：

1. **明确目标与现实约束**：梳理你为什么想发展副业或个人事业，以及当前能投入的时间、短期收入需要和长期期待。
2. **盘点经验资产**：从工作项目、接单经历、长期兴趣、他人反馈和经常被请教的问题中，找出真正有案例支撑的能力。
3. **筛选并细分方向**：结合喜欢程度、能力依据、市场需求和现实条件，对候选方向进行比较，进一步明确具体人群、使用场景和要解决的问题。
4. **形成初步构想**：判断现阶段更适合从文档指南、一对一咨询还是接单服务等形式开始，并形成粗框架和最小验证动作。

完整版通常需要约 25–40 分钟，可以分多次完成。每个阶段开始时，教练都会告诉你当前进度、参考用时和本阶段成果；阶段结束时会先总结，再由你决定继续还是暂停。

如果时间有限，也可以使用 10–15 分钟快速版，先筛选出一个当前最值得验证的方向。

## 它主要解决什么问题

它适合帮助你处理这些常见困惑：

- 感觉自己没有什么特别的技能，不知道能卖什么。
- 工作经验很多，但一直没有系统梳理过。
- 会的东西太多，不知道应该先做哪一个。
- 有一个大致方向，但说不清具体服务谁、解决什么问题。
- 想做副业或知识产品，却不知道应该先做课程、咨询、文档还是接单。
- 担心花很多时间做出产品后没人需要，想先用更轻的方式验证。
- 擅长某些工作，但并不喜欢，不确定它是否适合作为长期事业。

## 适合哪些人

它主要适合两类用户：

- 有 3 年或以上工作经验，想在职场之外发展副业，或者为未来独立工作做准备的职场人。
- 已经在做接单工作的自由职业者，积累了一些方法和客户经验，想把零散服务进一步整理成产品的人。

你不需要已经是行业专家，也不需要拥有很大的粉丝量。只要你在某个领域有真实实践，做成过具体事情，或者已经有人向你请教、找你帮忙，就可以从中开始梳理。

如果你目前还没有任何实践经历，只是想快速寻找一个热门项目，这份 skill 能提供的帮助会比较有限。它更适合从真实经验出发，而不是凭空创造一个赚钱方向。

## 如何开始使用

安装完成后，可以直接对 Agent 说：

> 使用 $liz-experience-product-coach，帮我梳理适合自己的经验产品化方向。

也可以在开场补充一点自己的背景：

> 我做了 5 年运营，现在想发展一份副业，但不知道哪些经验可以变成产品。请使用 $liz-experience-product-coach 帮我梳理。

如果只有十几分钟，可以说：

> 使用 $liz-experience-product-coach 的快速版，先帮我找到一个最值得验证的方向。

交流时，可以把它当成一次和朋友的聊天，不用担心自己说得够不够专业，也不需要提前整理一份完整简历。

如果当前使用的 Agent 支持语音输入，更建议直接用语音回答。语音通常能带出更多经历和细节，你不需要先把语言组织得非常有逻辑，想到什么就说什么。教练会从这些看似零散的信息里帮你提炼重点，并在需要时继续追问。

尽量说出真实案例，包括当时帮助了谁、遇到了什么问题、你具体做了什么、最后产生了什么结果。暂时想不完整也没有关系，先从记得的部分开始。每次先用几句话说一个具体例子即可，需要细节时教练会追问，不必为了效果更好而一次写完全部经历。你可以纠正能力判断，也可以明确拒绝不想继续做的方向或交付方式。

每个阶段结束后，你可以继续，也可以先让教练输出可保存的阶段总结。下次把总结贴回来，就能从对应阶段继续，不必重新回答全部问题。

## 最后会得到什么

无论使用完整版还是快速版，完成本轮梳理后，你会得到一份可保存的「经验产品化起步构想单」HTML 页面；当前 Agent 支持生成 PDF 时，也会同时提供可下载的 PDF 版本。

报告分为三个部分：

- **产品构想｜第一版先做什么**：说清楚先服务谁、解决什么问题、用什么形式交付，以及第一版做到哪里。
- **判断依据｜为什么先选这个**：告诉你这个方向来自哪些真实经验，为什么优先考虑它，以及哪些已经有证据、哪些仍是假设。
- **验证行动｜接下来怎么验证**：告诉你下一步找谁、做什么、记录什么，并提供一段可以直接使用的验证消息。

实际方案依据你的经历与意愿形成，不统一推荐模板或课程。证据不足时会说明未知项和验证方式。这份结果是可以继续验证和完善的起步方案，不是已经制作完成的可售产品，不代表市场已经成立，也不承诺收入结果。

## 这次梳理不包含什么

这份 skill 的任务是帮助你从经验中形成愿意尝试的第一版产品构想，并知道如何开始验证；不只整理履历，也不代替完整产品制作。

报告会提供一段与当前证据阶段匹配的“第一条消息”，帮助你发起需求访谈、测试构想，或在证据充分时邀请少量用户内测。定价、完整产品制作、选题、标题、海报、销售页和发售活动属于方向确定后的下一阶段，不属于这次起步梳理。
