# 方法与判断依据

## 盘点与能力阶段

从三个入口找经历：工作中的项目与重复任务；专长中的硬技能与软技能；兴趣中长期实践并取得反馈的事情。补充自我观察、他人评价、经常被请教的问题。

不要仅问“有什么技能”，而是逐轮还原：谁遇到什么问题 → 用户承担什么角色 → 采取什么动作与判断 → 得到什么成果 → 是否重复成功或帮助他人成功。

原专栏的技能评分是启发式阶段描述，不是心理测量或资格认证：
- 知识阶段（原表低于60分）：学过、知道，缺少实践成果。
- 经验阶段（约70分）：亲自做成过，方法尚未反复验证。
- 技能阶段（约80分）：重复做成，已有相对可靠的方法。
- 教学阶段（约85分以上）：帮助别人做出过结果，有传递方法的证据。

默认用阶段和事例表达；用户需要分数时才解释上述参照，不制造精确分数。一次经验可以支持限定范围的经验分享，不自动意味着能够保证咨询结果。涉及要求专业资质的服务，不能用这个评分代替资格要求。

比较优势来自相对于某类人更有经验，不要求成为行业第一。局限可能形成适用人群，例如普通学历求职经验可能更贴近相似背景的人；不能把所有不足都包装成优势。

## 金喜擅与取舍

先从有依据的技能中筛出至多三个候选，再看市场需要与喜欢程度。

喜欢要落到工作过程：喜欢主题还是喜欢交付？愿不愿反复做、解释、修改、沟通？以往是否主动投入？“没有钱还愿意做吗”只是可选线索，不能把需要收入的人判作不热爱。

- 喜欢、擅长且有需求证据：长期优先方向。
- 擅长、有需求但不喜欢：可选短期现金流路径，不默认作为终身事业。
- 喜欢、能力尚不足：学习、实践、分享，先积累可验证成果。
- 有需求但不擅长：若有具体可信的互补伙伴，可考虑合作；没有就不假设能交付。
- 喜欢、擅长但需求不明：保留方向，补需求证据。

先了解用户短期收入压力、时间和希望摆脱的工作方式，再给取舍建议。不要劝用户放弃现有收入全职投入尚未验证的方向。

## 需求证据：听、看、问

听：谁反复来请教？问题原话、发生场景和后续行动是什么？
看：是否有同类付费产品、可观察的成交和使用反馈？存在竞品只是参考，不能证明该用户一定能卖。
问：目标用户最近一次遇到什么问题，如何解决，投入什么，结果哪里不足？

区分：
- 已发生的付费、接单、复购与使用结果。
- 具体请教、重复痛点、调研经历与现有解决成本。
- 同类市场参考。
- 讲师猜测、点赞、口头购买意愿。

不同证据回答不同问题，不用点赞推算付费率，不把口头意愿当成交，也不因无人请教就判定没有市场。缺少联网工具时指导用户搜集，禁止虚构竞品、销量和搜索词。

需求可从增加收益、节省成本或时间、完成必要任务、改善生活等理解。优先考虑重要且紧迫、用户愿意行动的问题。原专栏讨论过痛点、焦虑、改善和梦想的优先级，但本 skill 不将其固化成普遍规律；不鼓励制造焦虑促销。

## 细分

先做减法：服务过或熟悉的特定人群；完整工作中最有优势的具体环节。
必要时做加法：人群＋技能、行业＋技能、确实拥有的资源。不要为了差异化生造标签。
用一句话表达：帮助【具体人群】在【场景】解决【问题】，获得【可观察成果】。
补充“谁—做—搜”：谁在做什么时可能搜索什么词。未经搜索核实的词标注为候选词。
差异化是当前假设，可以在交付中形成；不让“独一无二”成为起步条件。
