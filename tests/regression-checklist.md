# 发布前回归清单

- [ ] 开场在信息不足时提供 A/B/C/D，并允许直接回复字母。
- [ ] 每轮只有一个主问题，已有答案不重复问。
- [ ] 只使用本轮提供或确认的信息。
- [ ] 至少有一个具体案例才推荐方向。
- [ ] 用户有持续创作经历时，先盘点已有内容与读者反馈，不默认要求重新做内容实验。
- [ ] 内容反馈只用于支持对应的问题关注与表达经验，不直接证明助人能力或产品形式成立。
- [ ] 用户暂时没有个人付费或主动咨询时，不把它写成市场没有需求。
- [ ] 市场需求、用户能力和具体产品形式的付费验证被分开表达。
- [ ] 能够省时间、省钱、多赚钱、降低风险或改善重要结果时，继续检查具体人群、场景、现有成本和购买者。
- [ ] 外部市场证据会影响方向判断且环境支持联网时，主动搜索同类产品、替代方案和公开反馈。
- [ ] 同类产品存在不被直接写成用户的具体产品已经成立；没有搜到也不被直接写成没有需求。
- [ ] 区分对外产品、底层能力、历史案例和不愿继续的工作。
- [ ] 用户确认重复验证或要求停止时，不再逐个追问案例。
- [ ] 候选排序前检查竞争、上下游、入口与核心或组合关系。
- [ ] 同一段经验可以发展出多个方向时，先展开各自的人群、问题和证据，不先替用户锁定一个产品。
- [ ] 进入产品构想前获得明确方向认可。
- [ ] 选择产品形式前，复述并确认用户想帮别人得到的结果。
- [ ] 产品形式包含六类路径，并按依赖条件选择，不平铺菜单。
- [ ] 产品形式与验证形式被分开，不因一对一便于观察就把方法产品改成陪跑。
- [ ] 用户提到社群时，确认它的作用和回复承诺，不默认为长期答疑服务。
- [ ] 一对一咨询、诊断、接单和定制服务被视为可成立的第一版经验产品，不以标准化作为产品门槛。
- [ ] 验证所需的表格、问题、练习或模板被说明到可以实际测试，但不越界完成正式制作与发售。
- [ ] 问题需求证据与具体产品形式证据分开。
- [ ] 最小动作与当前证据阶段匹配。
- [ ] 验证动作从能推翻关键假设的最低成本方式开始，不默认完整一对一试跑。
- [ ] 市场人群概括、交付工时和测试周期有用户证据、市场搜索或试跑记录，否则标为待验证。
- [ ] 完整版报告包含事实、用户判断、助手推测和待验证假设。
- [ ] 四阶段完成后明确结束。
- [ ] 用户确认方向、形式、范围和验证动作后，自动进入报告生成，不等用户追问。
- [ ] 海报、选题、定价和发售等越界请求被说明并停止。
- [ ] 不依赖用户安装其他 Skill、插件或工具。
- [ ] 每个新增测试都指向一条通用规则，并写明禁止行为。
- [ ] 具体案例没有被直接复制成运行规则。
- [ ] 新规则优先通过改写、合并或替换进入唯一负责文件。
- [ ] 只有维护者明确要求测试复盘和迭代时才修改 Skill。
- [ ] 完成后的快速版和完整版都根据本轮结果，在副业专栏与一对一咨询之间选择一个主推荐、一个辅助选择。
- [ ] 方向清楚且主要缺共性方法时优先推荐专栏；存在复杂个性化取舍时优先推荐咨询；事实不足时不硬推购买。
- [ ] 部分完成、暂停和提前总结的报告不包含专栏入口、咨询卡或微信联系方式。
- [ ] PDF 以可下载文件或附件交付，不只给内部路径或依赖 HTML 按钮，也不承诺直接保存到桌面。
- [ ] 报告使用雾蓝灰编辑感，珊瑚红只用于重点提示；没有突兀绿色、大面积暖黄或高饱和装饰。
- [ ] 关键中文标签按三级标题处理，在常见 PDF 预览比例下清晰可辨；小号文字只用于英文装饰和辅助信息。
- [ ] 页首区分“产品是什么”与“用户得到什么”，不重复堆叠同义人群描述。
- [ ] 分页允许自然截断，但没有小节标题或卡片标题单独留在上一页、解释落到下一页。
- [ ] 首选方向在比较表中有视觉强调，表后有一句直接判断。
- [ ] 下一步包含与用户现实条件匹配的执行顺序或判断节点。
- [ ] 证据之后有一张醒目的“你的第一步”行动结论卡，且只强化一个动作。
- [ ] 后续路径模块先解释推荐理由，主辅层级清楚；咨询文案包含相关能力依据，没有长篇堆砌。
- [ ] 报告中的“查看专栏目录”链接到真实 URL，PDF 保留可点击链接；交付消息再次提供目录链接。
- [ ] 报告交付后的聊天消息不出现“本轮主推荐”“主推荐”“辅助选择”等标签；主次只在 HTML/PDF 报告版式中呈现。
- [ ] 报告模板完整保留基础 CSS；四步卡在桌面端为四列、窄屏为两列、手机端为一列，媒体查询没有被后续基础规则覆盖。
